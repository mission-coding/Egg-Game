# Egg Game 🥚

A fun arcade game built with Python and Pygame. Move a basket to catch falling eggs, earn points, and protect your remaining lives.

## ✨ Features

- Falling eggs and basket movement
- Keyboard-controlled gameplay
- Five lives
- Score tracking and saved high score
- Background music and sound effects
- Game-over and restart functionality

## 🕹️ Controls

| Key | Action |
|---|---|
| Left Arrow | Move basket left |
| Right Arrow | Move basket right |
| Enter | Restart after game over |

## 🛠️ Technologies Used

- Python
- Pygame

## 🚀 How to Run

1. Install Python 3.
2. Install Pygame:

   ```bash
   python -m pip install pygame
   ```

3. Run the game:

   ```bash
   python egg.py
   ```

## 📁 Project Structure

- `egg.py` — Main game file
- `gallery/` — Images, sounds, and high-score data

Keep the `gallery/` folder alongside `egg.py`.
